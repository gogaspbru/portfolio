# SWPlus — карточка продукта

Вёрстка страницы по макету Figma «ЦИФРОВОЙ ПРОГРЕСС» (кадр «Карточка продукта SOLIDWORKS»),
в стиле dipro.ru. Простые файлы, без сборки: `index.html`, `css/styles.css`, `js/main.js`, `img/`.
Посмотреть локально: `python3 -m http.server` в корне репозитория → `/swplus/`.

## Шрифты

В макете — PT Root UI (текст) и Mabry Pro (заголовки). Их файлов в репозитории нет,
поэтому в `--font-body` / `--font-head` они стоят первыми, а запасные — Golos Text и Onest
(Google Fonts). Если на dipro.ru шрифты свои — подключите их `@font-face`, и они подхватятся.

## Что подключить

- Кнопки «Купить онлайн», «Запросить счёт», «Скачать SWPlus», «Инструкция», ссылки меню — `href="#"`.
- Видео в блоке 03 — пока превью-картинка с кнопкой play.
- Форма «Есть вопросы?» проверяет поля и показывает «Спасибо», отправку надо подключить к бэкенду (`js/main.js`).
