# Тринити — главная страница (лендинг)

Статичная вёрстка по макету Figma «TRINITY», фрейм `174:129`.
Чистый HTML + CSS + JS; Vite — только dev-сервер и сборка.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
```

Можно и **без сервера и без npm**: просто откройте `index.html` двойным кликом
(или `dist/index.html`). Скрипты обычные, не ES-модули, поэтому меню,
анимации, видео и плавный скролл работают и с диска (file://).
Шрифт Conthrax с диска в Chrome может не подгрузиться (ограничение браузера);
в `dist/` он встроен в CSS и работает везде.

## Структура

```
index.html                 разметка; секции — отдельные блоки (удобно резать на компоненты Битрикса)
index-matrix.html          вариант первого экрана: «матрица точек» (WebGL) вместо видео
index-cubes.html           вариант первого экрана: кубики на синем, от курсора расходятся волны (WebGL)
index-line.html            вариант первого экрана: диагональ поворачивается, «закрывает» блок с видео и заливает экран синим; на синем — «О Тринити»
css/variables.css          @font-face + все токены: цвета, сетка, радиусы, высоты, анимации
css/main.css               стили по БЭМ-блокам, адаптив в конце файла
js/main.js                 точка входа (вызывает функции из window.Trinity)
js/hero-video.js           фоновое видео первого экрана (десктоп, без reduced-motion)
js/hero-matrix.js          «матрица точек»: сетка точек, знак из data-mark поднимается при прокрутке
                           (чистый WebGL без three.js; без WebGL остаётся CSS-фон)
js/hero-cubes.js           «волны по кубикам»: кольцевые волны от курсора/клика + постобработка (без мыши волны сами)
js/line-scene.js           «линия»: поворот диагонали, улёт параллелограмма, заливка синим (по мотивам santalarch.com)
js/header.js               прилипающая шапка
js/mega-menu.js            выпадающее меню (≥ 1200px)
js/menu.js                 бургер-меню (< 1200px)
js/reveal.js               построчное появление заголовков
js/count-up.js             «набегание» цифр
js/card-pixels.js          «пиксельный прожектор» на карточках
js/smooth-scroll.js        инерционный скролл колесом
                           (скрипты обычные, не модули; порядок подключения — внизу index.html)
assets/img/                фото карточек
assets/img/icons/          SVG-иконки и логотип из макета
assets/video/              poster.jpg + trinity-glass-waves-1080p.mp4 (кладётся вручную)
assets/fonts/              Conthrax (в git не попадает — см. .gitignore)
```

## Блоки (БЭМ) → компоненты Битрикса

| Блок            | Где                         | Что внутри |
|-----------------|-----------------------------|------------|
| `.hero`         | первый экран                | видео-фон, сетка, шапка, заголовок, CTA, новость |
| `.header`       | внутри `.hero`              | логотип, `.nav`, телефон, поиск, «Партнёрам», бургер |
| `.news-card`    | внутри `.hero`              | последняя новость |
| `.cta`          | внутри `.hero`              | кнопка-ссылка «Подобрать сервер» |
| `.about`        | «О Тринити»                 | заголовок, `.link-more`, `.direction-card` ×2 |
| `.stats`        | цифры                       | 4 × `.stats__item` (модификаторы цвета) |
| `.grid-lines`   | декор                       | вертикальные линии сетки (`--light` / `--dark`) |

## Брейкпоинты

- ≥ 1200 — десктоп (макет 1600, сетка тянется пропорционально; контейнер max 1600px)
- < 1200 — меню в бургер, новость под кнопкой
- < 1024 — блоки «О Тринити» и карточки в столбик, цифры 2×2
- < 768  — мобильная версия, видео не грузится (только постер)
