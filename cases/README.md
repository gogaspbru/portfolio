# Кейсы

Каждый кейс — отдельная папка со своей страницей:

```
cases/
  _case/case.css   — общие стили всех кейсов (сетка 1600 → var(--k), мобильная 375 → var(--m))
  _case/case.js    — общие анимации: появление блоков, параллакс, видео по скроллу, бегущие ленты
  kultura-doma/
    index.html     — страница кейса (откроется как /cases/kultura-doma/)
    img/           — картинки из макета Figma (webp, 2x)
    video/         — видео кейса (см. ниже)
```

## Видео

Страница ищет файлы в `cases/<кейс>/video/`. Для «Культуры дома»:

- `hero.webm` и/или `hero.mp4` — первый экран (под логотипом);
- `screen.webm` и/или `screen.mp4` — экран в белой рамке на фоне бархата.

Пока файлов нет, вместо видео показывается постер из макета с медленным «дыханием».
Видео играют без звука, по кругу и только когда видны на экране.

Пережать исходник в лёгкие файлы:

```
ffmpeg -i source.mov -vf "scale=1920:-2,fps=25" -an -c:v libvpx-vp9 -b:v 0 -crf 36 -row-mt 1 hero.webm
ffmpeg -i source.mov -vf "scale=1920:-2,fps=25" -an -c:v libx264 -crf 24 -preset slow -movflags +faststart hero.mp4
```

## Новый кейс

Скопируйте папку `kultura-doma`, поменяйте тексты и картинки. Классы `c-*` и атрибуты
`data-in` (появление текста), `.c-reveal` (раскрытие картинки), `data-speed` (параллакс),
`data-marquee` (бегущие ленты), `data-video` (видео по скроллу) работают на любой странице,
которая подключает `../_case/case.css` и `../_case/case.js`.
