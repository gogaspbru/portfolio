# Тринити — главная, версия 2

Вёрстка по макету Figma «Frame 42» (файл TRINITY, страница Tr2, node 327:2935), ширина 1600.
Чистые HTML/CSS/JS, блоки по БЭМ — удобно резать на компоненты Битрикса.
Отдельный проект: первая версия лежит в `../trinity-landing` и не меняется.

## Запуск

Без сервера и без npm: открыть `index.html` двойным кликом (или `dist/index.html`).
Скрипты обычные, не ES-модули, поэтому всё работает и с диска.

Для разработки:

```
npm install
npm run dev      # http://localhost:5174
npm run build    # сборка в dist/
```

## Структура

```
index.html                 разметка: шапка, первый экран, синий блок (направления + «О Тринити»)
css/variables.css          шрифт Conthrax, цвета и размеры из макета
css/main.css               стили блоков и адаптив (1399 / 1199 / 1023 / 767)
js/reveal.js               построчное появление заголовков
js/line-hero.js            линия на первом экране: при прокрутке ложится на край синего блока
                           и «закрывает» параллелограмм
js/hero-video.js           видео в параллелограмме (десктоп, без reduced-motion; иначе — кадр-постер)
js/menu.js                 меню по кнопке-сетке
js/card-pixels.js          «пиксельный прожектор» при наведении на карточки
js/smooth-scroll.js        плавный скролл колесом
js/main.js                 точка входа
assets/img/                картинки и иконки из макета
assets/video/              видео и постер (кадр из макета)
assets/fonts/              Conthrax — НЕ в git (десктопная лицензия), кладётся вручную
```

## Блоки (БЭМ)

- `header` — таблетки: меню-сетка, телефон, центр (лого + меню + «Конфигураторы»), поиск, «Партнёрам»
- `site-menu` — меню по кнопке-сетке
- `hero` — заголовок, текст, кнопка `cta`, фигуры `hero__shapes` (видео + «стекло»), линия `hero__line`
- `directions` / `direction-card` — карточки «производство», «интеграция»
- `about` + `link-more` — «О Тринити»

## Что не по макету / на заметку

- Блока с цифрами в макете нет — его нет и здесь.
- Кадр в параллелограмме — это кадр видео `trinity-glass-waves-1080p.mp4`; на десктопе играет само видео.
- Фото карточек из Figma (PNG по 5 МБ) пересохранены в JPG шириной 1500px (2× от размера в макете).
- Ссылки — заглушки `#…`.
