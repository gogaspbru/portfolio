# TWINS 1

Главная страница студии TWINS. Сетка и поведение — по референсу (присланные скриншоты),
тексты — с текущего сайта TWINS, картинки пока заглушки.

Простые файлы, без сборки: `index.html`, `css/styles.css`, `js/main.js`, `assets/`.
Залить папку `twins-1` по FTP как есть. Посмотреть локально: открыть `index.html`
через любой локальный сервер (например, `python3 -m http.server` в корне репозитория).

## Блоки (в `index.html` помечены комментариями «БЛОК N»)

0. Шапка: логотип и бургер-меню (цвет сам инвертируется от фона).
1. Первый экран на всю высоту: подпись, заголовок, кнопки «Портфолио» и «Консультация».
2. «Проекты»: сетка с зазорами 4px, ряды 2 / 3 / 2 / 3 / 2; подпись по наведению.
3. Утверждение по центру + публикации (пока названиями — заменить на логотипы).
4. Категории на изогнутой ленте, крутятся при прокрутке.
5. Утверждение слева + цифры (часть цифр — заглушки).
6. «Почему с нами?»: текст и фото пополам (пункты — заглушки).
7. Широкое фото.
8. Вопросы и ответы (заглушки).
9. Подвал с контактами.

## Картинки

Заглушки — `<div class="ph ..." data-label="4:5">`: подпись показывает нужные пропорции.
Заменить на `<img src="assets/img/....jpg" alt="...">` внутри того же места, стиль
`width:100%; height:100%; object-fit:cover`.

## Анимации (js/main.js)

Первый экран: фото медленно «отъезжает», текст и кнопки поднимаются. Заголовки и тексты
появляются снизу при прокрутке, картинки проявляются снизу вверх; карточки в ряду — лесенкой.
Лента категорий вращается вместе с прокруткой. Цифры досчитываются. Вопросы раскрываются плавно.
Меню выезжает сверху. При системной настройке «уменьшить движение» анимации отключаются.
