# Кейсы

Каждый кейс — отдельная папка со своей страницей:

```
works/
  _case/case.css   — общие стили всех кейсов (сетка 1600 → var(--k), мобильная 375 → var(--m))
  _case/case.js    — общие анимации: появление блоков, параллакс, видео по скроллу, бегущие ленты
  kulturadoma/
    index.html     — страница кейса (откроется как /works/kulturadoma/)
    img/           — картинки из макета Figma (webp, 2x)
    video/         — видео кейса (см. ниже)
  lindera/
    index.html     — кейс Lindera (/works/lindera/)
    lindera.css    — стили, нужные только этому кейсу
    img/, video/   — картинки 2x из Figma и запись прокрутки сайта (screen.webm/mp4)
```

## Видео

Страница ищет файлы в `works/<кейс>/video/`. Для «Культуры дома»:

- `hero.webm` и/или `hero.mp4` — первый экран (под логотипом);
- `screen.webm` и/или `screen.mp4` — экран в белой рамке на фоне бархата.

Видео уже лежат в папке (hero — фильм бренда v31, кадр по центру 1.8:1; screen — запись прокрутки сайта).
Если файла нет, вместо видео показывается постер с медленным «дыханием».
Видео играют без звука, по кругу и только когда видны на экране.

Пережать исходник в лёгкие файлы:

```
ffmpeg -i source.mov -vf "scale=1920:-2,fps=25" -an -c:v libvpx-vp9 -b:v 0 -crf 36 -row-mt 1 hero.webm
ffmpeg -i source.mov -vf "scale=1920:-2,fps=25" -an -c:v libx264 -crf 24 -preset slow -movflags +faststart hero.mp4
```

## Новый кейс

Скопируйте папку `kulturadoma`, поменяйте тексты и картинки. Классы `c-*` и атрибуты
`data-in` (появление текста), `.c-reveal` (раскрытие картинки), `data-speed` (параллакс),
`data-marquee` (бегущие ленты), `data-video` (видео по скроллу), `data-count` (числа считаются
при появлении) работают на любой странице,
которая подключает `../_case/case.css` и `../_case/case.js`.

Цвет, в который плавно перекрашивается страница у блока `.c-dark`, задаётся атрибутом
`data-tint="r,g,b"` (по умолчанию тёмный 18,19,23; у Lindera зелёный 93,109,99).
