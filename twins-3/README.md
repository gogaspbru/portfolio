# TWINS 2

Главная страница студии TWINS. Сетка и поведение — по референсу (присланные скриншоты),
тексты — с текущего сайта TWINS, картинки пока заглушки.

Простые файлы, без сборки: `index.html`, `css/styles.css`, `js/main.js`, `assets/`.
Залить папку `twins-1` по FTP как есть. Посмотреть локально: открыть `index.html`
через любой локальный сервер (например, `python3 -m http.server` в корне репозитория).

## Блоки (в `index.html` помечены комментариями «БЛОК N»)

0. Шапка: логотип и бургер (меню пока выключено — `MENU_ENABLED` в `js/main.js`).
1. Первый экран на всю высоту: подпись, заголовок, кнопка «Консультация».
2. «Избранные проекты»: сетка с зазорами 4px, ряды 2 квадрата / 3 вертикальных / 2 квадрата / 3 горизонтальных.
3. Утверждение по центру + логотипы журналов (`assets/press/`).
4. Направления «Дома / Квартиры / Коммерческие объекты» — карточки 3:2 на изогнутой ленте.
5. Утверждение слева + цифры (часть цифр — заглушки).
6. Светлый подвал с контактами.

## Картинки

Заглушки — `<div class="ph ..." data-label="4:5">`: подпись показывает нужные пропорции.
Заменить на `<img src="assets/img/....jpg" alt="...">` внутри того же места, стиль
`width:100%; height:100%; object-fit:cover`.

## Анимации (js/main.js)

Первый экран: фото медленно «отъезжает», текст и кнопка поднимаются. Заголовки и тексты
появляются снизу при прокрутке, картинки проявляются снизу вверх; карточки в ряду — лесенкой.
Лента категорий вращается вместе с прокруткой. Цифры досчитываются. При системной настройке «уменьшить движение» анимации отключаются.
